# IP Orbit

**Explore IP Addresses. Understand Networks. Discover Locations.**

IP Orbit is a web-based IP address lookup and geolocation platform designed to help users explore public IP addresses, understand network information, and visualize approximate geographic locations through an interactive map.

## Features

- **IP Address Lookup:** Retrieve information about public IP addresses.
- **Public IP Detection:** Detect a public IP address.
- **IP Validation:** Validate public IP addresses.
- **Geolocation:** View approximate city, region, and country information.
- **Interactive Map:** Visualize IP-based locations on a map.
- **Network Information:** Explore hostname, organization, postal code, and timezone.
- **User Authentication:** Separate login and registration system.
- **Responsive Design:** User-friendly interface across different devices.

## How It Works

1. Enter a public IP address or request IP detection.
2. The application validates the IP address.
3. IP Orbit retrieves available information through the IPinfo service.
4. The retrieved network and location details are displayed.
5. The approximate geographic location is visualized on an interactive map.

## Important Notes

- Supports public IPv4 and IPv6 lookups.
- Private and non-global IP addresses are rejected.
- IP-based geolocation provides approximate locations, not exact GPS coordinates.
- Location accuracy depends on available geolocation data.

## Project Objective

To simplify public IP address exploration by combining network information, geolocation, and interactive map visualization in one platform.
